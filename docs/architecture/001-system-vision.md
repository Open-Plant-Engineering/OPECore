
# OPECore System Vision

OPECore is not a CRUD application.

OPECore is an Engineering Repository Engine.

The repository manages:

- Elements
- Hierarchy
- Attributes
- Sessions
- Claims
- Changesets
- Synchronization

Goals:

- Massive scalability
- Complete history
- Offline support
- Future branching
